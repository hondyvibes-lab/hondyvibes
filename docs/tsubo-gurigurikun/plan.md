### ここから言えること
- **製品名で検索して来る人は少ない**(月750未満)。つまり「ツボぐりぐり君 使い方」で検索上位を取っても母数は小さい。

- 一方で競合がほぼいないので、**検索してくる少数の購入者に対しては、ほぼ独占的に届けられる**。
  → 役割分担:ショート動画=悩みで集客 / YouTube長尺や固定投稿=製品名検索の受け皿。

## 2. ポジショニング

**「整体師の解説」ではなく「挫折しかけた愛用者の実践記録」**

- 伸びている投稿者の多くは整体師・トレーナー。解剖学の解説では勝てないし、資格なしで語るとリスクが高い。
- hondyの強み = 実際に効果を感じている当事者であること。体験・手順・失敗談で勝負する。
- ターゲット:**持っているのに使いこなせていない人/痛くて放置している人**(第一)、購入を迷っている人(第二)。

## 3. 表現ガイド(薬機法・景表法・ステマ規制)

| ❌ 使わない | ✅ 言い換え |
|---|---|
| 腰痛が治る/改善する | 私はお尻まわりがほぐれた感じがする |
| 坐骨神経痛に効く | (病名は出さない) |
| 骨盤矯正/歪みが治る | 寝る前のリラックスタイムに |
| 誰でも効果がある | 私の場合は/個人の感想です |
| 骨盤職人より優れている | (他社比較で優劣を言わない。事実の違いのみ) |

- アフィリエイトリンクや提供品の場合は **#PR 表記必須**(2023年10月〜ステマ規制)。
- 毎回入れる注意書き:「痛みやしびれが出たら中止」「持病・妊娠中・産後は医師に相談」。
- 首への強い刺激、長時間使用の推奨はしない(説明書の範囲を超えない)。

## 4. シリーズ案(ショート動画 10本)

| # | タイトル案(フック) | 誰のどんな悩み | 根拠 |
|---|---|---|---|
| 1 | ツボぐりぐり君、持ってるのに使いこなせてない人へ | 買ったが放置している人 | フォームローラーで同型が97万再生 |

| 3 | 寝る前3分、お尻だけやってみて | お尻・腰まわりがガチガチ | 「寝る前に○回」型が大量に伸びている。お尻は評価が最も安定 |
| 4 | 穴の位置、ここで全然変わる(部位別早見) | どこに玉を挿すか分からない | 説明書が分かりにくい/ブログ間で記述が矛盾 |
| 5 | 土台がグラつく人はこれを敷いて | 「グラつく」不満 | レビュー不満 |
| 6 | 腰に当てると反って痛い人の当て方 | 体格で腰がうまく当たらない | NotebookLM分析「腰は個人差」 |
| 7 | 小玉が届かない問題、こう使う | 小玉が土台に阻まれる | レビュー不満 |
| 8 | 1か月続けた正直な変化 | 続ける価値があるか知りたい | 当事者性=差別化 |
| 9 | やりすぎ注意:1回何分まで? | やりすぎて揉み返し | 説明書の目安+安全配慮 |
| 10 | デスクワーク後の椅子でできる?試してみた | 在宅・オフィスワーカー | NotebookLM「発信の空白」。**要検証** |
